This page takes you from an empty project to a registered generator and three beacons, a secret, drawn values and a draw that anyone can check.

## Install

```sh
dotnet add package NCode.Randomness
dotnet add package NCode.Randomness.Curby
dotnet add package NCode.Randomness.Nist
dotnet add package NCode.Randomness.Drand
```

`NCode.Randomness` is the generator and the draw API. Each other package adds one beacon, and you need one only for a draw that others check.

## Register the generator

`AddRandomness` registers `ISecureRandom`, and each `Add…Beacon` call adds a beacon that draws are made from. Building the host fetches nothing, because a beacon contacts its service only when a draw asks it to. To go further, see how to [add beacons](/guides/add-beacons/).

## What it does. What it does not.

<CardGrid>
<Card title="It does">

- Run an SP 800-90A HMAC_DRBG per processor, seeded from the operating system.
- Mix each verified pulse into that generator and never use a pulse alone for a secret.
  [ADR-1000](https://github.com/NCodeGroup/Randomness/blob/main/docs/decisions/1000-beacon-randomness-is-mixed-into-a-local-generator-and-never-used-alone-for-secrets.md)
- Verify every pulse against a pinned anchor before any byte is used.
- Fetch pulses in the background, so no random value waits on the network.
- Draw unbiased values of every integer type.
- Make draws that anyone can reproduce from one pulse, by the algorithm `ncode-randomness-draw/1`.

</Card>
<Card title="It does not">

- Use a beacon's bytes alone for a secret. Everyone who reads the beacon sees the same bytes.
- Stop the application when a beacon is down. [Outages](/concepts/outages/)
- Verify CURBy-Q's Bell test or its extraction in process.
  [ADR-1007](https://github.com/NCodeGroup/Randomness/blob/main/docs/decisions/1007-curby-q-rounds-are-verified-as-curbys-client-verifies-them-and-their-extraction-is-left-to-curby-verify.md)
- Keep a key safe in the array `GetBytes` returns. [Make a secret](/guides/make-a-secret/)
- Make a draw secret. Anyone can recompute it from the pulse.

</Card>
</CardGrid>

## In the packages

- Four packages: `NCode.Randomness`, with the generator and the draws, and `NCode.Randomness.Curby`,
  `NCode.Randomness.Nist` and `NCode.Randomness.Drand`, one adapter for each beacon.
- The target framework is `net10.0`, which the badge shows and
  [nuget.org](https://www.nuget.org/packages/NCode.Randomness#supportedframeworks-body-tab) lists.
- Every C# sample on this site is a test the pull request build compiles and runs.
- The reasons behind the design are on record in
  [docs/decisions](https://github.com/NCodeGroup/Randomness/tree/main/docs/decisions).
- Apache License 2.0, copyright NCode Group. A vulnerability is reported privately, as the
  [security policy](https://github.com/NCodeGroup/Randomness/blob/main/SECURITY.md) says.

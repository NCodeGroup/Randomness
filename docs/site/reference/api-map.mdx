## Extension members

`RandomSourceExtensions`, `RandomnessServiceCollectionExtensions`, `RandomnessBuilderExtensions`, `RandomnessHealthChecksBuilderExtensions`, `CurbyRandomnessBuilderExtensions`, `NistRandomnessBuilderExtensions` and `DrandRandomnessBuilderExtensions` are C# 14 `extension` blocks compiled to ordinary static extension methods, so a project on an earlier C# version calls them the same way, or in their static form.

## Packages

```sh
dotnet add package NCode.Randomness
dotnet add package NCode.Randomness.Curby
dotnet add package NCode.Randomness.Nist
dotnet add package NCode.Randomness.Drand
```

Each package targets `net10.0`, and nuget.org lists its target framework on its Frameworks tab.
